Лотерейный билет представляет собой 7 различных случайных натуральных чисел из диапазона от 1 до 
49 (включительно), разделенных символом пробела и идущих в порядке возрастания. Напишите функцию generate_lottery_ticket(), которая с помощью модуля random генерирует лотерейный билет и возвращает его в виде строки.

Примечание 1. Приведенные ниже тесты – это лишь примеры ответа. Возможны и другие варианты генерации лотерейного билета.

Примечание 2. Вызывать функцию generate_lottery_ticket() не нужно, требуется только реализовать ее.
