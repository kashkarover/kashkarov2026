Для игры в бинго требуется карточка размером 5×5, содержащая различные (уникальные) целые числа от 1 до 75 (включительно), 
при этом центральная клетка является пустой (она заполняется числом 0).
Напишите функцию generate_bingo(), которая с помощью модуля random генерирует и возвращает случайную карточку для игры в бинго в виде списка списков, содержащих целые числа.

Примечание 1. Приведенные ниже тесты – это лишь примеры ответа. Возможны и другие варианты генерации карточки бинго.

Примечание 2. Вызывать функцию generate_bingo() не нужно, требуется только реализовать ее.
