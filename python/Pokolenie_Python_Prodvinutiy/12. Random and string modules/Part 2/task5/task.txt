Тайный друг 🕵🏻🌶️
Напишите функцию get_secret_friend(), которая принимает кортеж учеников students, случайным образом назначает каждому ученику его тайного друга, который будет помогать ему решать задачи по программированию, и возвращает словарь, где ключом является ученик, а значением – назначенный тайный друг.

Примечание 1. Обратите внимание, что нельзя быть тайным другом самому себе и нельзя быть тайным другом для нескольких учеников.

Примечание 2. Гарантируется, что в кортеже учеников более одного значения.

Примечание 3. Приведенные ниже тесты – это лишь примеры ответа. Возможны и другие варианты выбора тайного друга.

Примечание 4. Вызывать функцию get_secret_friend() не нужно, требуется только реализовать ее.

Примечание 5. Порядок элементов в результирующем словаре не учитывается.
