IP-адрес состоит из четырех чисел из диапазона от 0 до 255 (включительно), разделенных точкой.

Напишите функцию generate_ip_address(), которая с помощью модуля random генерирует и возвращает случайный корректный IP-адрес.

Примечание 1. Приведенные ниже тесты – это лишь примеры ответа. Возможны и другие варианты генерации ip-адресов.

Примечание 2. Вызывать функцию generate_ip_address() не нужно, требуется только реализовать ее.
